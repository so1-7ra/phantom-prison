# Phantom Prison 企画書（GDD）

## 1. コンセプト

> **幽霊が囚われた刑務所から、霊を封じた瓶を「静かに」運び出せ。**

- ジャンル：協力型の回収ホラー（1〜4人）
- 参考作品：R.E.P.O.、Lethal Company、Phasmophobia
- プラットフォーム：PC（Steam）。試作は itch.io で公開する
- エンジン：Godot 4
- **全クリはない。** 夜ごとにノルマが上がり、いつか必ず失敗する。記録は「何夜目まで生き延びたか」

### 他のゲームとの違い
**運ぶ荷物そのものが敵になる。** 霊瓶は揺らす・ぶつける・投げると封印が弱まり、0 になると中の幽霊が逃げ出してプレイヤーを襲う。
「急ぎたいのに急げない」というもどかしさと、仲間のミスで大惨事になる笑いが、このゲームの柱になる。

## 2. ゲームの流れ（1回の夜）

```
ロビー（装備を買う）
  ↓
夜開始：刑務所をランダム生成
  ↓
探索 → 霊瓶を見つける → 静かに運ぶ → 搬出口で売却
  ↓（制限時間 3 分。ノルマを達成したら [F] で途中終了してもよい）
ノルマ判定
  ├ 達成 → 次の夜（ノルマ ×1.35、霊瓶の価値と危険度も上がる）
  └ 未達成／全滅 → 「収監」：ゲームオーバー。最高記録を保存して最初から
```

## 3. 主な仕組み

### 3.1 霊瓶と封印（実装済み）
| 項目 | 内容 |
|---|---|
| 封印値 | 100 から始まる。0 になると幽霊が逃げ出す |
| ダメージ | 1 物理フレームの速度変化が 1 m/s を超えると、超えた分×8×もろさ |
| 封印が低下したとき | 50 未満になると瓶が勝手にガタつく。色が青から赤に変わり、光が点滅する |
| 売却額 | 価値 ×（0.5 + 0.5 × 封印値/100）。丁寧に運ぶほど高く売れる |
| レア瓶 | 価値は約 2.5 倍、もろさは 1.6 倍 |

### 3.2 幽霊（一部実装済み）
| 種類 | 動き | 状態 |
|---|---|---|
| 逃げた霊 | 壁をすり抜けて常に追ってくる | ✅ |
| 徘徊霊 | 2 夜目から出現。近づくと追ってくる | ✅ |
| 看守霊 | 決まった巡回ルートを回る。ライトで照らすと怒る | 予定 |
| 囁き霊 | ボイスチャットの音量に反応する | 予定（協力プレイ実装後） |
| 模倣霊 | 霊瓶に化けている。掴むと襲ってくる | 予定 |
| 重い霊 | 2 人で運ぶ必要がある大きな棺 | 予定 |

### 3.3 刑務所の生成（実装済み：基本形）
- 5×5 のグリッドを迷路として掘り、15% の確率で抜け道を追加する
- 今後の予定：部屋をパーツとして組み合わせる方式に移行し、独房・食堂・処刑室・看守室などを用意する
- 区画の種類を増やす：地下牢、廃病院棟、水没区画、焼け落ちた棟（夜が進むと解放）

### 3.4 成長要素（予定）
- 稼いだお金の一部は手元に残る。ロビーで装備を買える
  - 防振ケース（封印へのダメージ半減）、台車、霊鎮めの塩、強力なライト、霊探知機
- 幽霊図鑑：初めて捕まえた幽霊を記録する。図鑑を埋めることも長く遊ぶ目的になる
- 見た目の解放：作業服、ヘルメット、ボディカメラなど

### 3.5 協力プレイ（予定）
- 2〜4 人
- 近くの人にだけ聞こえるボイスチャット。死んだ仲間の声は幽霊にしか聞こえない、などの演出を入れる
- 2 人で運ぶ重い荷物を用意して、協力が必要な場面を作る

## 4. 長く遊べるようにする仕組み
1. **毎回違う夜**：ステージ・霊瓶の配置・幽霊の組み合わせがランダム
2. **上がり続けるノルマ**：必ずどこかで失敗するので、毎回が新しい挑戦になる
3. **記録**：到達した夜の最高記録（実装済み）、今後はオンラインランキング
4. **収集**：幽霊図鑑と見た目のアイテム
5. **予定外の出来事**：物理演算と仲間のミスから、配信映えする場面が生まれる
6. **定期アップデート**：幽霊や区画を少しずつ追加して、遊んでいる人を飽きさせない

## 5. 見た目と音の方向性
- ローポリ＋ざらついたテクスチャ（PS1 風）。少人数でも作れて、雰囲気も出しやすい
- 暗闇を懐中電灯で照らすのが基本。霊瓶の光が、目印にもなり危険の合図にもなる
- 音：霊瓶のガラスが軋む音で、封印が危ないことがわかるようにする
